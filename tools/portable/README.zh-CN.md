# 独立副本管理脚本

本目录是安装、启动、归档卸载和恢复工具的源码，不是完整安装包。公开仓库不包含游戏本体、Minecraft运行时、贴图或替换影片。

`tools/build_portable.py`使用明确提供的本地游戏、API、已导出后端运行时、影片和校验清单生成本地安装包。当前源码协议为25，HK与Minecraft必须配套构建；具体前置资源见仓库根目录README。

安装器复制本地HK游戏到新的独立位置，拒绝覆盖已有目录，仅管理匹配安装ID的启动链接、存档链接和文件。

卸载采用同级目录归档，保留项目及独立存档；归档内的恢复工具可恢复原位置。归档不释放占用空间。执行前关闭对应独立游戏和Minecraft，并检查目标路径。
